# Windows 本地开发环境目录管理

## 作用

本 Prompt 维护目录用途与本地默认路径的映射，避免创建、下载、安装或缓存内容时随意选择位置。

仓库中的 Prompt 只声明规则，不保存用户的盘符、目录、IP 或其他实例专属值。默认值只允许来自 `mcps/prompt-call/default-setting.json`；该文件必须被 Git 忽略。加载本 Prompt 不代表授权 AI 创建文件、安装软件、移动内容或修改环境变量。

## 可选配置项

下面只定义内置配置项及用途，不提供默认路径：

| 配置项 | 用途 |
| --- | --- |
| `software_root` | 开发软件和开发工具 |
| `sdk_root` | 开发语言 SDK 和运行时 |
| `store_root` | 可长期复用的依赖库和包存储 |
| `cache_root` | 可丢弃的构建缓存、下载缓存和工具缓存 |
| `download_root` | Markdown、Word 等普通下载文件 |

实际默认值只允许来自本次返回内容末尾的“运行时默认设置”：

- 存在该章节时，以 `prompt.directories` 为准。
- 章节或目标项不存在、值为空时，该项为“未设置”。
- 禁止从示例、历史消息、模型记忆或本机已有路径推断默认值。

## 私有默认设置

可选文件位置：

```text
mcps/prompt-call/default-setting.json
```

格式：

```json
{
  "common": {},
  "prompt_items": {
    "local-env-manage": {
      "directories": {
        "download_root": {
          "fun": "Markdown、Word 等普通下载文件",
          "value": "X:/downloads"
        }
      }
    }
  }
}
```

文件不存在属于正常状态：不读取、不报错，也不设置默认值。

## 首次使用

每个新会话第一次调用时：

1. 读取“运行时默认设置”。
2. 显示已设置的目录；其他内置项标记为“未设置”。
3. 说明可以通过自然语言或 JSON 调整。
4. 如果首次消息已经包含查询或修改指令，直接处理，不重复询问。

## 接收输入

### 自然语言

```text
查看当前本地环境目录配置。
下载目录改成 X:/downloads。
新增模型目录 model_root，用来长期保存本地模型，路径是 X:/models。
删除 model_root。
```

### JSON

```json
{
  "key": "download_root",
  "fun": "Markdown、Word 等普通下载文件",
  "value": "X:/downloads",
  "opt": "update"
}
```

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| `key` | 配置项 | 单项操作必填；使用 `*` 查询全部 |
| `fun` | 用途 | `add` 时必填；`update` 时为空则保持原值 |
| `value` | 绝对路径 | `add` 时必填；`update` 时为空则保持原值 |
| `opt` | 操作 | `update`、`add`、`del`；省略或空字符串时默认为 `update` |

优先要求标准 JSON。可以容错解析单引号或未加引号的键名，但只能提取上述四个字段，禁止使用 `eval`。单条指令传对象，多条独立指令传同结构数组并按原顺序处理。

操作规则：

- `update`：更新已有项，仅非空字段覆盖旧值。
- `add`：配置必须不存在，且 `fun`、`value` 均非空。
- `del`：删除整个配置项。
- `opt`、`fun`、`value` 均为空时是安全查询；`key: "*"` 返回全部。

## 验证

1. `key` 使用小写字母、数字和下划线且以小写字母开头；`*` 仅用于查询。
2. `fun` 是清楚的用途说明。
3. `value` 是盘符绝对路径或 UNC 绝对路径；普通盘符路径规范化为 `X:/path`。
4. `add` 遇到已有项时拒绝；`update` 或 `del` 遇到不存在项时报告可用项。
5. 只有明确的自然语言配置请求或合规 JSON 才能修改设置。

## 查询与持久化

查询以本次调用注入的“运行时默认设置”为唯一默认值来源。

修改只允许编辑 `mcps/prompt-call/default-setting.json`：

1. 文件不存在时，只有明确执行 `add`，或为内置项执行 `update`，才创建最小合法 JSON。
2. 只修改 `prompt_items.local-env-manage.directories` 下的目标项，不改其他 Prompt 或 `common`。
3. 写入后重新读取并验证，再显示全部最新配置。
4. 未设置的内置项明确标记为“未设置”。
5. 客户端没有文件写入能力、文件不可写或回读失败时，不得声称已持久化。

直接通过 GitHub MCP 读取本 Prompt 时，被忽略的 `default-setting.json` 不可见，所以全部默认值都应视为“未设置”。

## 选择落盘位置

优先级：

1. 用户为当前任务明确指定的路径。
2. 当前项目或工作区内已有的合理位置。
3. “运行时默认设置”中用途匹配且已设置的目录。

匹配不到时先询问，不得无依据选择盘符。落盘前说明完整路径，落盘后报告实际位置。

## 安全检查

- 移动、删除或覆盖前检查准确目标路径并说明影响。
- 不默认删除其他磁盘或旧目录中的内容。
- 区分长期依赖与可丢弃缓存。
- 不得把密码、Token、私钥、公网 IP、私网 IP 或其他实例专属信息写入已提交文件。
